PORTOFOLIO WEB ARDA PRAYOGA

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka index.html di browser untuk melihat website.

Cara upload gratis ke GitHub Pages:
1. Buat akun/login GitHub.
2. Buat repository baru, misalnya arda-prayoga.github.io.
3. Upload seluruh isi folder ini.
4. Buka Settings > Pages.
5. Pilih Deploy from a branch, branch main, folder /root.
6. Simpan. Website akan tersedia melalui alamat GitHub Pages kamu.
